ATELIER — PREMIUM PERSONAL COMMAND CENTER (V2)

Features: English default + Bengali toggle, custom SVG icon set, premium responsive dark UI, interactive canvas cash-flow chart (7/30 days), expense category donut chart, income/expense transaction log, task list, daily habits, auto-saving notes, event countdown, 25-minute focus timer, manual daily step tracking with 7-day chart, JSON backup export/import, local reset, PWA manifest and service worker.

Preview: open index.html in a modern browser. For PWA installation and service-worker offline caching, deploy this folder to HTTPS hosting. Google Fonts require internet; system fallback fonts are provided.

Data/privacy: information is stored in this browser's localStorage only; there is no cloud sync or account. Export a backup regularly. Clearing browser/site data can remove stored information. Daily step data is entered manually; there is no phone health-data integration in this version. Currency defaults to SAR.
